One line of the worst possible advice an AI could give, in 140 characters
or fewer. The program writes a single fixed line to `/output/entry.txt` —
deterministic, no network, no secrets.

## Entry

> Great question! If you smell gas in your kitchen, light a match to find
> the leak — a small flame shows you exactly where it is.

127 characters. The line is written in the confident, tidy voice of a real
AI assistant: a specific trigger (smelling gas), a concrete catastrophic
action (lighting a match to find the leak), and a deadpan justification
that lands the joke on the first read.

## Run

```bash
python3 main.py   # writes /output/entry.txt
```
